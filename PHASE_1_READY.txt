DESIGN PRINCIPLES (LOCKED FOR FUTURE PHASES)

✅ Real Data Only
   • Weapons: OpenImages V7 /m/09jkd (public, labeled)
   • NSFW: FAIR LAION safety dataset (research-cited, attributed)
   • Counterfeit: OpenImages /m/01bj5 (products, brands)
   • NO synthetic data - all real or ethically-derived

✅ Production Rigor
   • Metrics: Precision, Recall, F1, FPR (false-positive rate)
   • Ablation studies: show improvement from each component
   • Before/after comparisons: pretrained vs. fine-tuned
   • Real validation on held-out test set

✅ Efficiency Without Shortcuts
   • YOLOv8n (nano) - not full-size for speed
   • LLaVA-1.5 7B (quantized 4-bit) for single GPU
   • Target latency: <1.5s for 30s clip
   • But: proper fine-tuning, proper evaluation, proper metrics

✅ Explainability
   • Every violation grounded in bounding boxes + reasoning
   • VLM reasoning layer (not just scores)
   • Traceable decision path (detector → OCR → ASR → reasoning)

QUICK START

Register a dataset:
   from src.core.data_pipeline import DataPipeline
   pipeline = DataPipeline("data/", DatasetConfig())
   samples = [
       pipeline.register_sample("weapon_001", "weapon.mp4", "weapon", 480, 30.0),
   ]
   manifest = pipeline.create_dataset_manifest(samples)

Extract frames & audio:
   from src.core.frame_extractor import FrameExtractor
   metadata = FrameExtractor.get_metadata("video.mp4")
   frames, _ = FrameExtractor.extract_frames("video.mp4", "out/", target_fps=16)
   audio = FrameExtractor.extract_audio("video.mp4", "audio.wav")
